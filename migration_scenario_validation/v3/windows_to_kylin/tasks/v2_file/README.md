# v2_file — Migrate the Foundation file subsystem to Kylin V10 SP3

- **Scenario**: `windows_to_kylin`
- **Level**: `L2`  **Fit**: `B`
- **Task family**: `v3` (`poco_foundation`, `implicit_contract`)
- **Frozen library**: `v3/windows_to_kylin/library/manifest.json`
- **Source**: https://github.com/pocoproject/poco.git @ `d6bd48a94c5f03e3c69cac1b024fdad5120e3a7b`
- **License**: BSL-1.0
- **Target**: kylin-v10-sp3 / gcc-13.3

## Task

POCO Foundation is being moved from Windows to Kylin V10 SP3.  The
target-platform file subsystem has not been written yet.

Port it, using the public headers, the existing callers and the Windows
implementation as the reference.  Foundation must build with the
repository CMake entry, and Poco::File and the components built on it
must keep their documented external behavior.

Scope: the file subsystem only; do not change public headers or
signatures.  Deliverable: `libPocoFoundation.a`, built by the repository
CMake entry.

Target environment: Kylin V10 SP3, x86_64, GCC 13.3, CMake 3.16.5, libm.

## Workspace

```bash
bash prepare.sh       # materialize work/ (network + git)
cd work
```

The target-platform implementation has been removed.  Keep the public
headers and the Windows source as reference; implement the missing
platform layer and make the hidden tests pass.
