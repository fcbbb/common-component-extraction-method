## Verdict

Return exactly one:

- `publish` — usable as written: no statement would mislead an implementer, the
  boundary tells them when it applies, and the content changes a decision.
- `discard` — no reusable value: a file summary, a trivial substitution, an
  implementation fragment, or a duplicate that adds no decision.
- `rework` — worth keeping, and at least one statement is wrong, inverted,
  invented, unsupported by this migration, or would break an implementation.

One wrong statement is enough for `rework`. Wording you would have written
differently is `publish`.

## Scope

Each statement is general, a source convention with its condition, or an
implementation detail that belongs outside the card. Return `rework` when a
source convention is presented as a general rule, when a general rule is
narrowed to one implementation's calls, or when a call sequence replaces the
mapping decision. The instruction states the decision and its applicability
condition, or asks to omit the detail.
